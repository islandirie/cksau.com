# Project Summary: cksau.com

This project is a personal portfolio website for showcasing work, built with HTML, CSS, JavaScript, and some Python for automation. The main features and structure are:

- **Pinterest-style gallery** (`index.html`): Displays images from the `images` directory, with categories and sorting handled by JavaScript (`sorting.js`). Image paths are auto-generated by a Python script (`filenames.py`), which writes them to a JS file (`filenames.js`).
- **Responsive design** (`styles.css`): Uses CSS media queries for mobile, tablet, and desktop layouts.
- **Menu bar** (`menubar.js`): Injects a top navigation menu into each page.
- **Playground features**:
  - **Image viewer** (`play.html`): Lets users browse AI-generated seamless images with interactive controls.
  - **Box wrapping estimator** (`play/boxwrapestimator.html`): Calculates how many boxes can be wrapped with a given size of gift wrap.
  - **GPT formatter tool** (`play/gpt-formatter/gpt-formatter.py`): Flask app for formatting job postings using OpenAI.
- **Resume page** (`resume.html`): Shows professional experience and education.
- **No backend database**: Hosted on AWS S3 for static site delivery, with CDN and domain management.

The project is designed for cost-efficiency, easy maintenance, and quick content updates.
